# IR x Tech Field Guide

A one-page guide for an international relations major thinking about tech and startups: sourced numbers, five career paths, a seven-question quiz that reorders them, a plan and resources.

Every figure and posting in `lib/data.ts` was read on 2026-11-09 and links to its source.

```bash
npm install
npm run dev      # local
npm run build    # static export to out/
```

Built with Next.js, Tailwind and motion.
